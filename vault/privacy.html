VAULT Privacy Policy

Effective date: September 20, 2026

VAULT is a local-first music archive and release-planning application. This policy explains how the shipping VAULT 1.0 experience handles information.

1. Overview

OnlyTruePerspective LLC does not require users to create a VAULT account for the shipping VAULT 1.0 experience. Core catalog, playback, release-planning, and backup workflows are designed to operate on the user’s device.

2. Data collection

Based on the shipping VAULT 1.0 code audit, OnlyTruePerspective does not collect personal data through VAULT. VAULT does not include OTP analytics collection, advertising identifiers, behavioral profiling, or tracking.

VAULT does not collect VAULT account information because the shipping experience does not require a VAULT account. VAULT does not automatically upload a user’s music catalog to OnlyTruePerspective or send music to an OnlyTruePerspective server for processing.

3. Music and user content

Imported music, artwork, metadata, Song Dossiers, release-planning information, and related catalog data are stored locally on the user’s device in VAULT’s app storage. This information stays there unless the user explicitly exports or shares data through system functionality.

4. Network and server use

The core VAULT 1.0 experience does not require an OnlyTruePerspective server. The shipping code audit found no VAULT network requests for the core product workflow. VAULT can be used offline for its local catalog, playback, release-planning, and backup functions.

5. Backups and exports

Users may choose to create and export portable .vaultbackup files. The backup workflow includes SHA-256 integrity validation before restoration. When a user chooses to share or save an export, the destination app, service, device, or storage provider selected by that user may handle the exported file under its own policies.

6. Apple services

Apple may independently process information related to App Store distribution, TestFlight, device and platform services, and crash or diagnostic information when a user chooses to share it with Apple. That processing is governed by Apple’s privacy policies and is separate from OnlyTruePerspective’s data collection through VAULT.

7. Third-party services

The VAULT 1.0 code audit found no third-party analytics, advertising, crash-reporting, or cloud database SDKs in the shipping app.

8. Children

VAULT does not knowingly collect personal information from children.

9. Security

VAULT’s local-first design reduces exposure to a centralized application server. No device, operating system, storage location, or export destination can be guaranteed completely secure. Users should protect their devices and any exported backup files appropriately.

10. Data retention

OnlyTruePerspective does not maintain a server-side VAULT user-data retention database for the shipping VAULT 1.0 experience. Local VAULT data remains on the user’s device until the user deletes it, removes the app, or exports and restores data according to the app’s behavior.

11. Deleting data

Users can remove tracks and Song Dossiers from VAULT using the app’s deletion controls. Removing the app generally removes its local app storage from that device. Exported .vaultbackup files and any device backups remain until the user deletes them from the location where they were saved.

12. Changes to this policy

OnlyTruePerspective may update this policy to reflect changes to VAULT or applicable requirements. The current version will be published at this URL with an updated effective date.
