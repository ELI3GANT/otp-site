VAULT Privacy Policy

Effective date: November 20, 2026

VAULT is a local-first music archive and release-planning application. This policy explains how the current VAULT app handles information.

1. Overview

OnlyTruePerspective LLC does not require users to create a VAULT account. Core catalog, playback, release-planning, and backup workflows are designed to operate on the user’s device.

2. Data collection

The current VAULT app does not send personal data to OnlyTruePerspective through app-initiated network requests. The app does not include OTP analytics collection, advertising identifiers, behavioral profiling, or tracking.

VAULT does not require an account and does not automatically upload a user’s music catalog to OnlyTruePerspective or send music to an OnlyTruePerspective server for processing.

3. Music and user content

Imported music, artwork, metadata, Song Dossiers, release-planning information, and related catalog data are stored locally on the user’s device in VAULT’s app storage. This information stays there unless the user explicitly exports or shares data through system functionality. If you use recording or video-export features in your installed version, microphone access records only when you choose, and Photos access saves exports only when you request it.

4. Network and server use

The current VAULT app does not require an OnlyTruePerspective server. VAULT can be used offline for its local catalog, playback, release-planning, and backup functions.

5. Backups and exports

Users may choose to create and export portable .vaultbackup files. The backup workflow includes SHA-256 integrity validation before restoration. When a user chooses to share or save an export, the destination app, service, device, or storage provider selected by that user may handle the exported file under its own policies.

6. Apple services

Apple may independently process information related to App Store distribution, TestFlight, device and platform services, and crash or diagnostic information when a user chooses to share it with Apple. That processing is governed by Apple’s privacy policies and is separate from OnlyTruePerspective’s data collection through VAULT.

7. Third-party services

The current VAULT app includes no third-party analytics, advertising, crash-reporting, or cloud database SDKs.

8. Children

VAULT does not knowingly collect personal information from children.

9. Security

VAULT’s local-first design reduces exposure to a centralized application server. No device, operating system, storage location, or export destination can be guaranteed completely secure. Users should protect their devices and any exported backup files appropriately.

10. Data retention

OnlyTruePerspective does not maintain a server-side VAULT user-data database. Local VAULT data remains on the user’s device until the user deletes it or removes the app. Exporting a backup does not remove the originals. Device or iCloud backups may include the app container, according to your Apple settings.

11. Deleting data

Users can remove tracks and Song Dossiers from VAULT using the app’s deletion controls. Removing the app generally removes its local app storage from that device. Exported .vaultbackup files and any device backups remain until the user deletes them from the location where they were saved.

12. Changes to this policy

OnlyTruePerspective may update this policy to reflect changes to VAULT or applicable requirements. The current version will be published at this URL with an updated effective date.
