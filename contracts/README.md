# Pinned OTP contracts

These JSON files are generated by OTP CORE and checked in so OTP Site remains
independently deployable. Do not edit artifacts or the pin manifest by hand.

- Verify offline: `npm run contracts:verify`
- Synchronize from a sibling CORE checkout: `npm run contracts:sync`
- Synchronize from another layout: set `OTP_CORE_CONTRACT_SOURCE` to CORE's
  `contracts/generated` directory, then run `npm run contracts:sync`

After synchronization, review the contract diff and run the booking handoff
and full Site suites. Contract synchronization never changes payment ownership.
